## ⚡ Quick Start (5 minutes)

### Step 1: Install Dependencies

```bash
cd DebugDivas
npm install
```

### Step 2: Verify Setup

```bash
npm run dev
```

Should open `http://localhost:5173` and show the DevFix.AI interface ✅

### Step 3: Create Your Branch

**Each team member creates their own branch:**

```bash
# Team Member 1 - UI Components
git checkout -b feature/ui-components

# Team Member 2 - Core Logic
git checkout -b feature/core-logic

# Team Member 3 - AI Prompts
git checkout -b feature/ai-prompts

# Team Member 4 - Log Storage (handles saving logs!)
git checkout -b feature/log-storage

# Team Member 5 - Utilities & Integration
git checkout -b feature/utilities
```

## 🎯 What You're Building

**DevFix.AI** - AI-powered debugging assistant

### Core Features:
1. ✅ Paste error logs (Node.js, Python, Docker, CI/CD)
2. ✅ AI analyzes and explains the error
3. ✅ Get instant fix code and commands
4. ✅ **All logs are automatically saved** 💾
5. ✅ Search through past errors
6. ✅ Export/import log history
7. ✅ Beautiful dark-themed UI
